# ADR 0021 - Private unified task with separate authority

Compose one bounded private parent through the existing research, workspace, validation and repair APIs. Use stable child identities and fenced publication, rather than duplicating source checks, exact approvals or the sandbox. Authenticate each human decision separately and preserve it when recovering the task.

Expose a bounded typed model contract while keeping the supplied provider deterministic. No trusted coding model is available in this environment. Preserve citation integrity, fixture provenance and narrow validation scope in every claimed result. Leave genuine-model evaluation and wider reliability boundaries to later work.
