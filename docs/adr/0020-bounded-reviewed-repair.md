# ADR 0020 - Compose repair through existing authority boundaries

Use a private, bounded repair parent over the exact workspace and validation child contracts. Admit only verified actionable Go failures. Pin root-package validation scope and image, and retain each preimage, patch, approval and report identity. Require scoped human review for every patch.

Bind child side effects to a current parent lease as well as their own existing fences. Reconcile by exact immutable receipts instead of issuing replacement changes. Publish the parent completion only when the child report and policy identities match. Cap repeated proposals and distinguish infrastructure from source failure.

Keep deterministic fixtures and trusted manual proposals. A genuine coding model and broader integration are separate work.
