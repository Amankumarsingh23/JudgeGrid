# Repository research permissions

Build with `go build ./cmd/repo-research`. The CLI requires `--allow-development-research`, `REPO_RESEARCH_ENABLED=true`, `APP_ENV=development`, `DEV_AUTH_ENABLED=true`, a fixed `DEV_PRINCIPAL`, and explicit `REPO_DATABASE_URL`. Use the already configured private repository storage and pinned retrieval and context helper paths. Run the usual migration manager against the intended database first. The CLI is absent from normal container images and has no HTTP route. It is an operator process; local credentials, environment and database access are within the operator trust boundary.

With the opt-in flag present, use `--action create --index <ready-index> --goal lease`, then `--action resume --run <id>`. Use `show` for the owner-scoped journal and verified citation metadata, and `cancel` to clear the active claim. The built-in fixture also supports `outbox`, `cache` and a bounded search question. A planner that explicitly requests approval pauses the run. The authenticated operator calls `grant` or `deny` with `--run`, `--step` and the exact `--digest`. The built-in fixture never asks for approval.

The only tools are hybrid `search_code`, verified chunk `read_source`, verified `lookup_symbol`, bounded `inspect_graph`, and independently verified `inspect_evidence`. Inputs are exactly a bounded query or a lowercase content ID. Owner, repository, snapshot, index and commit come from the trusted run and are resolved again by existing authorized readers. No model arguments may set a principal, a path, an arbitrary URL or executable code. Approval authorizes one existing read action under the same policy and scope. It grants no shell, edit, test, network, SQL, Git or publishing capability.

Repository-derived metadata remains untrusted input. The planner cannot dispatch tools, change owner, emit a final claim, decide an approval or bypass bounds. Strict JSON rejects duplicate and unknown fields, unexpected types, excessive size and depth, and unregistered operations. Raw source and complete pack text remain transient; private journal observations retain citations and bounded metadata. Treat CLI arguments and output as private; use an operator environment with appropriate history and log handling.

Telemetry uses an allowlist of operation names and coarse success/error outcomes. No private identifier or content is a metric label. It is optional and does not decide run state.
