# Repository research run schema

Migration 0017 adds runs, logical steps, physical attempts and action-bound approvals. It is independent of judge execution leases. Run scope, creation time and deadline are immutable. A step starts with an immutable canonical decision and digest over run ID, pinned scope, planner policy and ordinal. A guarded transaction adds one observation. Physical attempts are append-only and include claim generation.

A run starts CREATED, enters PLANNING when claimed and RUNNING before a dispatched read. WAITING_APPROVAL releases its claim. An exact, unexpired grant returns it to CREATED with the pending action still journaled. Denial cancels, and expiration is recorded using database time. Cancellation also closes a pending approval and invalidates the lease. Repeating the same authorized grant or denial is idempotent; mismatched digests, principals, or choices are rejected. A grant must still be unexpired at dispatch.

Claims combine the run owner, an opaque token, monotonic generation and a database-clock deadline. Writers renew and fence their claim in a short transaction, including cancellation interlocks through the run row. A process that crashes before writing a tool result leaves its decision and attempt durable. Takeover re-authorizes a replay and can create another physical attempt under the same logical step. A committed observation is reused. Inflight immutable reads may finish after cancellation, but the stale process cannot publish their result.

Fixed policy permits three active runs and twelve admissions per principal in an hour. A run has a 15-minute deadline, 12 planner calls and logical positions, 12 physical tool attempts, three attempts per step and five physical query-bearing attempts. Planner stage deadline is five seconds and tool stage deadline is 110 seconds; the existing reader and pack limits still apply. The journal caps individual decision and observation bytes, charges up to 64 KiB of inspected or packed payload and up to 8,192 context WordPieces across committed observations. These are payload accounting units, independent of the readers' separately bounded full-file verification work and the absence of an LLM tokenizer.

A finish writes a terminal observation and COMPLETED in one transaction. Backend, invalid policy and budget outcomes use bounded failure classes. The journal stores historical references rather than source contents. It is private application state and is not a replacement for database role separation or a tamper-evident audit log against database administrators.
