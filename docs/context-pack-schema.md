# Context pack schema 1

Packs are ephemeral typed results; no authoritative source/retrieval state is written. The policy pins reranker/input/intent/graph/ranking/diversity/citation/tokenizer/budget behavior. Pack identity hashes scope, complete policy, outcome, intent, budget and the exact serialized context. Timing diagnostics are excluded from identity. Floating-point scores may vary across platforms; same-environment deterministic ordering and documented inference tolerances are tested.

`Pack.Scope` retains owner, repository UUID, source snapshot/full commit, analysis index/manifest, retrieval index/policy/manifest, context policy and SHA-256 of the exact private query. There is no cross-owner context/model-result cache. Policy/model mismatch fails explicitly instead of silently reinterpreting historical packs.

`Pack.Context` is the **actual budgeted payload**: canonical UTF-8 JSON with schema marker `judgegrid-evidence-v1`, scope and evidence. Its exact WordPiece count is `Consumed`; `Remaining=Budget-Consumed`. The outer API diagnostics, candidate list and omission records are not prompt payload and are not claimed to be covered by that token budget. An answering system must use the decoded `Context` string and account separately for its own model tokenizer/message overhead.

Each evidence object includes contiguous E1/E2 identifiers, original chunk/file/symbol IDs, exact path/language/byte and line span, original chunk SHA-256, exact selected-source SHA-256, verbatim decoded source, direct/graph provenance, baseline/lexical/dense/RRF ranks, actual reranker logit/rank, selection reason, parse status and partial-span flag. Columns are zero-based UTF-8 byte columns, lines one-based, and spans half-open. A cropped citation never implies the full original chunk was included.

Source spans first select the highest-scoring verified window. If the full structured payload does not fit, the actual tokenizer searches suffix boundaries, recomputes byte/line positions and source hashes, and re-counts the complete serialized payload. Hash tokenization can make length changes nonmonotonic; the fitter promises a checked fitting result, not an optimal knapsack or longest possible prefix. If even headers cannot fit, return empty context with INSUFFICIENT_EVIDENCE rather than exceeding budget.

Candidates retain all scored windows, possible/scored counts, byte coverage, partial/truncated metadata, original channel rankings and graph reasons. Omission codes include `duplicate_range`, `empty_source`, `overlap`, `block_limit`, `token_budget`, `headers_exceed_budget`. Weak evidence is a declared heuristic (negative maximum logits with no lexical path/symbol identity match), not a calibrated probability threshold. It can retain real evidence under an INSUFFICIENT_EVIDENCE status; it never manufactures text.

Outcomes include READY, NO_CANDIDATES, INSUFFICIENT_EVIDENCE, SOURCE_UNAVAILABLE, INTEGRITY_FAILURE, MODEL_UNAVAILABLE and TIME_BUDGET_EXCEEDED. Foreign/snapshot-mismatched requests return authorization errors without pack metadata. Model/source failures contain no invented evidence. Error strings, queries, paths, source hashes and content are never metric labels.

`Verify` re-authorizes READY scope, enforces the declared block and candidate/full-file byte limits before source reads, independently checks every byte/line/hash, and validates an actual bounded resolved path from each graph seed to its cited chunk. It reconstructs canonical context and independently counts the complete payload again. This verifies citations and policy/scoping/token integrity, not a cryptographic attestation of historical model relevance scores or an answer's correctness. There are no unverified cross-request source caches.
